# notebooks/

Jupyter notebooks for exploratory data analysis and tuning.

Guidelines:

- Notebooks are for exploration, not production. Anything you want to keep
  should be ported into `src/nfl_grades/` with tests.
- Clear outputs before committing (or use `jupytext` pairing). Large notebook
  outputs blow up the repo.
- Name notebooks `NN-short-description.ipynb` so the intended order is obvious.
