# 2026-04-23 — PBP ingest (E1)

Notes from building the `plays` table ingest and validating the first load.

## Source shape

`nflreadpy.load_pbp(seasons=[2024])`:

- 49,492 rows × **372 columns**
- 47,274 REG + 2,218 POST rows
- REG weeks span 1–18 (as expected).
- All 49 target columns present (see `pipeline/scripts/explore_pbp.py` —
  no missing / renamed fields as of nflverse 2026-04).

See `docs/adr/0011-thin-plays-table-in-postgres.md` for why we project
down to ~42 columns rather than storing the full 372.

## Type coercion gotchas

PBP delivers most nullable columns as `float64` (with NaN for "n/a")
rather than pandas nullable dtypes. That forces an explicit `_coerce`
function in `ingest/pbp.py` that:

- converts float `NaN` → `None` for every column type,
- casts `0.0`/`1.0` float flags → `bool`,
- casts numeric-valued floats (e.g. `yards_gained=7.0`) → `int`,
- extracts `.date()` from `pd.Timestamp` / `datetime` BEFORE the
  `isinstance(val, date)` branch, since `Timestamp` inherits from `date`
  (hit this in test).

Empty/`"nan"` text strings are also normalized to `None`.

## Ingest shape

- Grain: one row per `(game_id, play_id)`.
- Strategy: `DELETE WHERE season=:s` + chunked bulk INSERT (5k/chunk).
- 2024 season: 26 seconds end-to-end (includes cache miss + Parquet
  write at ~20 MB). 2025: 25 seconds.

## What this unlocks

With `plays` populated:

1. **QB v1 grading** — `docs/grading/qb-v1-proposal.md` can now read
   `SELECT ... WHERE qb_dropback AND season_type='REG'` directly and
   compute EPA/db, CPOE, success rate per passer.
2. **Garbage-time filter** — all inputs needed (`wp`,
   `score_differential`, `qtr`, `game_seconds_remaining`) are in the
   table.
3. **UI drill-downs** — the Mahomes-top-5 query in `verify_pbp.py`
   runs in <100 ms with the `plays_passer_season_idx` index.

## Known gaps (deferred)

- No FTN charting columns — `is_interception_worthy`, `is_qb_fault_sack`
  live in a separate nflverse feed and will be ingested alongside NGS
  in a later task. Their absence does not block QB v1.
- `plays.posteam` is raw text, not FK. If historical normalization
  matters for joins (STL → LAR, etc.), use `team_aliases` at read time.
- Pre-2016 seasons have no CPOE (EPA model started in 2006; CPOE added
  later). The v1 grading formula will need to either skip CPOE for
  those years or fall back to a CPOE-less composite via `data_tier`
  (ADR-0003).
